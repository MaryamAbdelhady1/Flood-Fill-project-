# Flood Fill & Graph Simulation Project

## Description
A Python project simulating graph algorithms using **OOP**.  
Uses **Tkinter** and **Pygame** for visualization.  
Computes **minimum weight paths** using **Dijkstra's algorithm**.  
Finds **shortest paths** using **BFS** or **DFS**, user can choose.

## Features
- Minimum weight path calculation with **Dijkstra**  
- Shortest path search using **BFS** or **DFS**  
- Interactive visualization with **Tkinter** and **Pygame**  
- Fully object-oriented design  

## Installation
1. Make sure you have **Python 3** installed.  
2. Install required libraries:

```bash
pip install pygame
pip install tk
```
## How to Run

Clone the repository:
```bash
git clone https://github.com/username/FloodFillProject.git
cd FloodFillProject
```
Run the main Python file:

```bash
python main.py
```

Follow the on-screen instructions to choose BFS, DFS, or Dijkstra.

## Controls / Usage
- **Left click**:
  - 1st click → select **source/start node**
  - 2nd click → select **destination/end node**
  - Any additional clicks → add **obstacles/walls**
- **Enter key** → start the algorithm visualization
